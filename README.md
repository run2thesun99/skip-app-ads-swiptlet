# Skip App Ads Swiplet

An independent Swipt-compatible Swiplet that looks for common ad skip controls across installed apps. It is not affiliated with or endorsed by the Swipt project.

## Add to Swipt

Open **Swiplets → + → Add Repository** and enter:

`https://raw.githubusercontent.com/run2thesun99/skip-app-ads-swiptlet/main/swiplets.json`

## Build from source

Install Bun, then run `bun install` and `bun run build` in this directory.

Detection focuses on skip labels and ad SDK controls near the upper-right screen corners. It cannot detect every ad or guarantee every match is safe.
